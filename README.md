# pstack

This repository contains the [pstack Cursor plugin](pstack/), a collection of
rigorous agent workflows for writing less, higher-quality code.

## Install

```bash
/add-plugin pstack
```

See the [pstack documentation](pstack/README.md) for setup, usage, and the full
skill reference.

## Repository structure

```text
.
├── .cursor-plugin/marketplace.json  # Marketplace manifest
├── pstack/                          # Plugin source and documentation
├── schemas/                         # Plugin manifest schemas
└── scripts/validate-plugins.mjs     # Marketplace validation
```
